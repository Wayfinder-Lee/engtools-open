# English Teacher's Toolkit — 英语教学材料准备工具箱

> 🌐 **官方网站：[www.engtools.cn](https://www.engtools.cn)** —— 无需部署，注册即用

面向初高中英语教师（中考 / 高考备考）的 AI 备课工具箱：浏览器端 SPA + 自有轻量 Node.js 后端。左侧栏按教学环节分组（词汇教学 / 写作教学 / 试卷整理 / 课堂素材），工作区一键切换**初中 / 高中学段**——初中模式隐藏读后续写，词汇上限、句式要求、词数与分值话术全面适配课标三级词汇与中考标准。注册即送全功能免费使用额度、按操作计费、兑换码充值，无需自备 API Key；同时保留「使用自己的 API Key」免登录直连模式（高级入口）。所有产出均可导出 DOCX / 打印 PDF / PPT。

## 在线使用与快速开始

- **直接使用线上站**：[www.engtools.cn](https://www.engtools.cn)（注册即送额度，无需自建）

本地开发前置要求：Node.js ≥ 20（Vite 8 与后端共同要求）。

```bash
npm install          # 安装依赖
npm run dev          # 开发模式（localhost:5173）
npm run build        # 生产构建
```

登录 / 额度功能依赖后端，二选一：

1. **本地起后端**：`cp server/.env.example server/.env` 填入数据库 / JWT / SMTP / LLM Key（详见 [server/README.md](server/README.md) 本地开发节），`cd server && npm start`；再在根目录 `cp .env.example .env`，把 `VITE_API_BASE` 指向 `http://localhost:9000`
2. **不部署后端**：页脚「使用自己的 API Key（高级）」进入直连模式（需自备任一 OpenAI 兼容 API Key），或直接使用线上站

## 个性化学案模块（✍️）

最复杂模块的完整流程：

```
批量上传手写图片（或扫码手机直传）→ 视觉模型 OCR（可校对）→ LLM 逐生生成学案 → 浏览器打印 PDF / 导出 Word → 班级讲评报告
```

- 一次上传多张图片（每张一位学生），批量 OCR → 批量生成，折叠卡片展示、可单独或打包下载
- OCR **自动识别答题卡姓名栏的手写姓名**（排除题干虚构落款）；相机默认名 / 纯数字文件名自动回填识别结果，实名命名的文件优先保留
- OCR 同时输出**手写书写质量评估**：1–10 分（衡水体标准）+ 字母形态 / 间距 / 基线 / 符合度 / 改进建议
- **扫码手机直传**：电脑端出二维码，老师用自己手机微信扫码免登录逐本拍，照片实时出现在电脑端接同一 OCR 流水（照片中转 ≤24h，完成任务即删，不关联学生身份）
- **班级讲评报告**：整班一次生成评讲课参考——共性问题（真实错例、全部匿名「有同学写道」）+ 建设性意见 + 亮点展示（高分原文具名摘句）+ 评讲课环节建议；客观统计（五档分布 / 分项均分 / 错误频次）由前端实时现算，与 LLM 叙事分离；导出 PDF（3 页）/ Word / 投影 PPT（五档分布竖向柱状图），**学生名单只进 PDF / Word，PPT 不带**

### 学案结构（9 模块）

1. **审题分析** — 偏题判断 + 要点覆盖
2. **作文总评** — 整体评价 + 参考分数（应用文 1–15 / 读后续写 1–25）
3. **错误分类诊断** — 语法 / 词汇 / 句式 / 逻辑，表格呈现
4. **重点语法突破** — 针对性规则讲解
5. **词汇升级训练** — 基础词 → 高级替换
6. **句式提升工坊** — 原句 → 分析 → 改进 → 技法
7. **范文升级版** — 应用文：称呼 + 3 段正文 + 署名，句子①–⑧跨段编号 +【技法】批注；读后续写：两段逐句批注表格（句子 + 功能/技法）
8. **续写专项分析**（仅读后续写）— 段首句衔接 / 主旨升华 / 描写多样性勾选表
9. **巩固练习** — 范文默写，中文翻译 + 句式提示 + 横线书写

### 输出格式

- **打印 PDF**：HTML 模板 + 浏览器原生打印，`@page { size: A4 }` 精确控纸、CSS 多栏 + 表格排版、每生严格 2 页、批量自动分页。纯前端方案，无需 Puppeteer / 后端渲染
- **Word**：`docx` 库逐生构建（表格列宽显式对齐版心），单份下载或 JSZip 打包全班 zip（重名学生自动加序号）

## 试卷排版助手（📄）

```
粘贴 / 上传 Word·PDF·照片·扫描件 →（无文字层自动分流视觉转写）→ LLM 大纲切块（附录识别、答案回填）→ 全结构可编辑 → 排版导出
```

- **上传分流**：docx / 有文字层 PDF 直接提取文字；照片多选与扫描件 PDF 走逐页视觉模型转写（5 credits / 页，页级重试 / 移除 / 预览）；无文字层 PDF 与学科网水印文字层（`{#{…}#}`）自动识别并分流视觉管线
- **LLM 大纲切块**：题型清单软先验（可编辑）+ 大纲锚点定位回全文（位置认领制 / 前导结构回退），正则切分降级为回退基座；题号守卫与题型比对仅作 advisory 提示
- **附录识别 + 答案回填**：文末参考答案等附加部分自动识别（正则漏检有弹窗补救、确认截断），答案清单按题号自动回填——不覆盖正文已有答案、重号卷按试卷顺序逐块消耗；听力类附录粘卷尾不切
- 每块独立状态，失败块单独「重试」并按原切块序插回
- 可编辑粒度到每道题（文章 / 选择 / 填空 / 写作 / 其他 5 种类型，题干、选项、答案），支持增删与上下移动
- 排版选项：A4 竖版 / 8K 横向双栏 / A3 横向双栏；五号 / 小五 / 小四字号；目标页数（自动调行距段距凑页，8K/A3 双面 1 张纸 = 2 页）

## 听力音频剪辑（🎧）

```
导入 MP3/WAV → 波形拖选 → 时间线编排（保留 / 删除 / 静音 / 模板音频 / TTS 合成语音）→ 试听 → 导出 MP3/WAV
```

- **纯本地剪辑**：波形 + minimap + 缩放拖选，所有处理在浏览器完成，音频不经过任何服务器
- **TTS 合成语音**：输入文字生成男 / 女声播报（云端一句话合成，三档语速），一键插入时间线——听力材料里的改题提示、指令补录不用再真人录音
- **变速不变调**（SoundTouch）：整段或选段调速，音高不变
- 会话自动存档（IndexedDB），关页面回来继续剪；导出 MP3（lamejs）/ WAV
- 服务端 TTS 为可摘除模块：未配置环境变量时功能自动停用，其余不受影响

## LLM API 模式

所有 LLM 调用通过 `src/services/llm.ts`，统一 OpenAI 兼容 Chat Completions：

- **登录态**：请求自有后端 `POST /api/llm/chat`（Bearer JWT），服务端持真实 Key 转发并按操作预扣额度（上游失败自动退款），浏览器全程不接触真实 Key
- **自带 Key 模式**：开发走 Vite 代理（`/api/proxy`）解决 CORS，生产直连自配 endpoint
- **模型**：自带 Key 模式各模块独立选择（`ModelSelect` 组合框：预设 MODEL_OPTIONS 6 项可下拉、也可手输任意模型名，OCR 另有视觉模型列表；空名/首尾空格在 `llm.ts` 统一拦截）；登录态由平台按操作指定（`utils/model.ts` 的 `PAID_MODELS`）

## 部署

- **前端**：`npm run build` 产物在 `dist/`，为纯静态文件（HTML + 带 hash 的 JS/CSS + 字体与静态资源），托管到任意静态服务 / CDN 即可；`index.html` 建议 `no-cache`，带 hash 的 `assets/*` 长缓存。构建链含 `scripts/split-keys.cjs`（遗留邀请码 Key 分片，源文件不存在时自动跳过）；登录功能依赖根目录 `.env` 的 `VITE_API_BASE` 指向后端公网地址
- **后端**：`server/` 为标准 Node.js HTTP 服务（默认监听 9000），可部署到任意函数计算 / 容器 / VPS 平台；环境变量按 `server/.env.example` 配置（`.env` 只用于本地，真实密钥只在服务端），接口细节见 [server/README.md](server/README.md)

## 开发约定

- 修改 `VocabItem` 字段 → 同步更新 types → Prompt → 表格列 → DOCX 导出
- 修改 Prompt JSON schema → 确保与 TypeScript 类型一致
- 写作模块的 essay 是 `string[]`（段落数组），不是单个 string
- 修改计费 → 同步 `server/src/index.js` 的 `CREDIT_COST` 与前端 `utils/model.ts` 的 `CREDIT_COST_LABELS`，并重新部署后端
- `server/.env` 与兑换码 CSV（`codes-*.csv`）不入仓库、不入部署 zip
- **隐私铁律**：学生姓名 / 照片不上主页、不进仓库；讲评报告叙事全部匿名化，具名表扬仅摘高分原文
- CSS 无框架，每个组件独立 `.css` 文件；中文排版默认宋体（CSS 字体栈 `"SimSun","宋体"`；docx `eastAsia: '宋体'`）
- 修改后执行 `npm run build` 验证（项目无测试框架）

常见问题

支持初中学段（中考）吗？

支持。切换到初中模式后，词汇范围锚定《义务教育英语课程标准（2022年版）》三级词汇（约1600词），提示词按中考标准生成。

生成的词汇可以直接默写吗？

可以。导出面板可选「默写清单」或「配套材料 → 词汇默写卷（含报词单）」，中文提示+空格作答，直接打印。

要收费吗？

注册即送体验额度，每段提取消耗 5 额度，生成失败自动退回；也可绑定自己的 API Key 使用。

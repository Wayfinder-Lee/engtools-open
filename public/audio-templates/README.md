# audio-templates — 听力模板音频库

「听力剪辑」工具的模板素材目录（当前为空，占位说明用途）。

使用方法：

1. 把 mp3 / wav / m4a / ogg 素材放进本目录（建议 mp3 / wav，浏览器解码最稳妥）
2. 到 `src/data/audioTemplates.ts` 的 `AUDIO_TEMPLATES` 清单里登记：
   `file` = 本目录下的文件名，`name` = 界面上显示的名字
3. 登记后模板按钮出现在「听力剪辑 · 加载音频」卡片里，点击即插入到时间线的
   播放头 / 选区起点位置

说明：

- 素材随站点静态部署（构建时本目录原样拷贝到 dist/），不经任何服务器处理
- 文件未登记就不会出现在界面上；登记了但文件缺失时，点击会给出友好的加载失败提示
- 建议素材类型：常用答题间隔（如 5s / 10s 静音）、固定时长提示音、考试开场白等
